# Azure Data Engineering Bootcamp

Study guides and slides for a free, live, online **Azure Data Engineering Bootcamp**. It takes you from cloud basics to a small end-to-end data project with **Azure Data Factory**, **Azure Data Lake Storage Gen2** and **Databricks**, and ends with guidance towards the Microsoft **DP-750** certification.

The project you build: **Azure SQL Database → Azure Data Factory → ADLS Gen2 (Parquet) → Databricks (Delta table) → Genie**.

## How to use these materials

- **study-guide.md** explains each topic and gives the steps, settings, code and troubleshooting tips. At the end you will find a **quiz** (with answers you can reveal) and an **assignment**.
- **slides.md** shows each slide as an image, with its text.
- Follow the sessions in order. Each one builds on the previous session.

## What you need

- A laptop or desktop with Google Chrome.
- A free Azure account (created in Session 1) and a personal email address.
- For Databricks (Session 5): a Databricks Free Edition account.

## Safety

- Never commit or share passwords, storage account keys, connection strings, access tokens or card details.
- Delete Azure resources when you have finished with them, to avoid charges.
- Menus, prices and exam details change over time. Check the official Microsoft and Databricks documentation.
